# data/Swissmedic/

Source data for **Swissmedic** (Swiss Public Assessment Reports (SwissPARs)).

## Source
- **Website:** https://www.swissmedic.ch/ (SwissPAR)
- **Document type:** Swiss Public Assessment Reports (SwissPARs)
- **Download method:** The SwissPARs were not downloaded by us. We received them as a complete folder of PDF files from Swissmedic.
- **Date of receipt:** 2025-01-19
- **Selection criteria:** all available SwissPARs

## Files
| File | Description |
|---|---|
| `Swissmedic_list.txt` | List of all downloaded PAR file names (234 documents), used to draw the random evaluation sample for manual annotation. Identical to `../inference_data/Swissmedic.txt`. |

SwissPARs exist only in English.

The PDFs themselves are stored locally in `downloads/` and are **not** part of the repository (`.gitignore`).

# analysis/1995/approved/overlap/

Overlap of drugs between agencies, and the order and time lags of approvals for drugs approved by several agencies.

| Subfolder | Drugs matched by |
|---|---|
| `Drug_name/` | Brand name (`Drug_name`) |
| `Non_proprietary_name/` | INN / active substance (`Non_proprietary_name`) |

**Created by:** `notebooks/analyze_overall.ipynb` with `DATASET_FILTER = ""`,
`DECISION_FILTER = "approved"` and `DRUG_COL` = name of the subfolder.
Matching is by exact (lower-cased) name.
